# Northline Studio

Сайт студии на Vue 3, Vite и GSAP. Включает портфолио, анимации прокрутки, форму заявки и отдельную админку на Node.js + SQLite.

## Запуск локально

Нужен Node.js 22.13 или новее (рекомендуется Node.js 24).

```sh
npm ci
cp .env.example .env.local
npm run build
COOKIE_SECURE=false npm start
```

- Сайт: http://127.0.0.1:8787/
- Админка: http://127.0.0.1:8788/admin/

Для разработки оставьте сервер запущенным, а во втором терминале выполните `npm run dev`. Откройте адрес, который покажет Vite.

## Админка и заявки

Создайте свою учётную запись в терминале:

```sh
npm run admin -- add owner
```

Команда запросит пароль. Готовых паролей в проекте нет.

Форма отправляет заявки на `/api/contact`. Они сохраняются в `data/leads.sqlite` и доступны в админке. Email-уведомления не подключены. После успешной отправки кнопка показывает Accepted, затем поля очищаются; форма остаётся открытой.

## Загрузка на GitHub

Распакуйте архив и загрузите содержимое папки `northline-studio` в репозиторий, включая скрытые `.gitignore` и `.env.example`. Изображения и видео уже включены в `src/assets`.

В архив не входят локальные базы заявок, личные настройки `.env.local`, зависимости `node_modules`, сборки, записи видео и отдельные демонстрационные копии сайта. Зависимости устанавливаются командой `npm ci`, сборки создаются командой `npm run build`.

GitHub хранит исходники. Для работы сайта вместе с заявками и админкой нужен хостинг с Node.js 22.13+. GitHub Pages обслуживает только статические файлы и не запускает этот сервер.

## Размещение на сервере

После `npm ci` и `npm run build` запустите `npm start` под менеджером процессов. Обратный прокси должен направлять основной сайт на порт 8787. Для адресов кейсов сервер уже возвращает страницу приложения. Админка работает отдельно на порту 8788; предоставьте доступ через защищённое подключение или локальный туннель.

При HTTPS оставляйте secure cookies включёнными (значение по умолчанию); `COOKIE_SECURE=false` используется только для локального HTTP. Данные SQLite храните на постоянном диске и резервируйте отдельно от репозитория.

Основные переменные сервера: `SERVER_PORT`, `SERVER_HOST`, `ADMIN_PORT`, `ADMIN_HOST`, `DATABASE_PATH`, `TRUST_PROXY`, `COOKIE_SECURE`. `VITE_CONTACT_ENDPOINT` задаётся при сборке фронтенда; пример находится в `.env.example`.
